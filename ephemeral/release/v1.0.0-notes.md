polytype v1.0.0 establishes a stable, explicit Go/JSON projection contract for JSON Schema, validation, generated Go codecs, structural TypeScript, devalue transport, and custom backends.

## Stable API

- Author schemas with `Declare`, typed `Field` references, `SealedUnion`, `Optional`, `Nullable`, and `Compose`.
- Invoke generation from build-tagged declarations through `go tool polytype`, or from executable Go configuration through `codegen.Gen`.
- Lower the validated closed grammar through the public `grammar` and `typegrammar` packages, then use the built-in TypeScript and devalue backends or write a custom projection.
- Deprecated `NewJSONSchemaMethod`/`NewJSONSchemaFunc` helpers and their remaining `With*` options stay source-compatible throughout 1.x.

## Wire contract and safety

- Ordinary fields are required and non-null. `Optional[T]` expresses absence; `Nullable[T]` expresses required nullability. Ambiguous direct pointers and ordinary omission tags are rejected before output changes.
- Named enums and sealed unions generate schema-aware JSON codecs. Enum aliases, unknown values, discriminator collisions, unsupported containers, and conflicting owner methods fail with diagnostics.
- Generated validation methods are compiled once and cannot disappear silently during regeneration.
- Removed or renamed registrations prune unchanged checksum-owned schema artifacts. Edited orphans are preserved and reported.

## Other projections

- `--typescript` emits structural declarations for the same admitted graph, with an optional type-only barrel.
- The devalue runtime and code generator support typed SvelteKit transport without coupling schema generation to JavaScript tooling.
- YAML is outside the generated v1 surface. Applications own any YAML-to-JSON conversion.

## Migration

The module moved from `github.com/tylergannon/go-gen-jsonschema` to `github.com/tylergannon/polytype`, and the generator is pinned with a Go 1.27 tool directive:

```bash
go get -tool github.com/tylergannon/polytype/polytype@v1.0.0
```

See the [v1 migration guide](https://go-gen-jsonschema.tylergannon.com/migration-v1/) for declaration, presence, enum, union, YAML, and generated-output changes.

The final published candidate was installed without a local replacement and passed Go encode/validate/decode tests, invalid-input rejection, strict TypeScript compilation, and unchanged regeneration.
