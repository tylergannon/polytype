# Material findings

1. **High — anonymous roots are returned without passing the grammar admission boundary.** `SchemaBuilder.LowerRoots` validates only `l.defs` (`internal/builder/typegrammar_root.go:50`), while the returned root nodes are not part of those definitions. As a result, a direct `[]byte` root is lowered to `Slice(Uint8)` and returns a nil error even though `Definitions.Validate` rejects the same byte-like slice when it is reachable from a definition (`typegrammar/validate.go:137-140`). A temporary bite test calling `pkg.Lower([]grammar.Root{{Type: types.NewSlice(types.Typ[types.Byte])}})` failed because no error was returned. This admits a shape the exported grammar explicitly excludes, contradicting #104's “no new admitted shapes” boundary. Add a validation path that covers both definitions and root nodes, with a regression for a forbidden anonymous root.

2. **High — the promised CLI diagnostic parity is false, and the test bypasses the CLI path that proves it.** For a registered `map[string]int` field, `builder.Run` returned `rendering struct field: rendering schema: mapType/chanType not allowed Holder at .../fixture.go:24:4`; the exported root path returned `lower root 0 (map[string]int): maps are outside the static type grammar at root.go:1`. `TestRefusedRootsMatchFieldLoweringText` avoids this mismatch by constructing `NewForTypes` with a nonexistent selected root (`grammar/grammar_test.go:196-211`) and then stripping both wrapper context and source position (`grammar/grammar_test.go:240-250`). That does not demonstrate issue #104's acceptance item that refused roots produce “the same diagnostic text the CLI prints,” nor the brief's instruction to compare against the existing builder behavior. Exercise `builder.Run` (or its actual admission path) and make the exported diagnostic match it exactly.

3. **High — issue #104's downstream-adoption acceptance item has not been completed or demonstrated.** The issue requires skgo's duplicate projection to be deleted and its generated TypeScript to remain byte-identical. This branch contains no skgo change, and the recorded scratch proof only called `grammar.Load` over skgo examples, lowered 18 of 20 roots, and explicitly says skgo does not project those two shapes (`ephemeral/worklog/202609061434-issues-104-107.md:241-262`); it neither deletes the existing projection nor compares generated TypeScript before and after. The issue cannot be closed on this milestone unless that acceptance item is completed or the issue is explicitly amended.
