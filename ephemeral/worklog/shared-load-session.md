# Shared invocation loading

- `packages.Config.ParseFile` runs after an in-process source read, while Config.Overlay in x/tools v0.52 invalidates dependency export reuse on typed loads. Metadata-only loading avoids both problems: Go selects files and compiler artifacts; the session parses captured root bytes directly and imports those artifacts with standard gcexportdata/go/types.
- Reusing independently loaded `*types.Package` graphs by import path is unsound. A session owns an export importer map and checks overlapping package/compiler/source identities before reusing it. A dependency first imported from export data cannot be promoted in place into a checked source root: a new universe preserves the old graph unchanged.
- Source captures supplied as Overlay need one metadata request. Without captures, selected roots use the ordinary go/packages read-after-discovery behavior. An initial extra compiler pass doubled acquisition work without being part of the standard loader contract; exact private snapshot ownership is now explicit in View. Metadata-only requests retain their requested mode and do not acquire compiler exports.
- A semantic hit returns a fresh packages.Package metadata wrapper, retaining the shared Types, TypesInfo and AST nodes. Returning the old wrapper dropped newly requested embed metadata. Consumer assertions must compare semantic objects, not wrapper allocation.
- Persistent producer cache identity excludes the optional session. The TypeScript generator checks its emission cache before any session activity; independent declaration configurations can miss that cache but share one checked source graph. Dirty source always rechecks.

- Real Gimbal integration exposed a material fallback hazard: calling raw `packages.Load` with the caller's full captured Overlay made x/tools parse the dependency graph (the downstream run was stopped at 43 seconds/14 GB). Unsupported analysis must return to the consumer's existing native-overlay/staging loader. `LoadWithFallback` preserves that per request, and `grammar.LoadWithLoader` carries it through lazy dependency loads. The callback runs outside the session lock; the regression proves callback selection and safe reentry.
- A second real consumer regression came from fallback staging declining overlays outside the host module. SKGO's private captures include local replacements; passing all those already-materialized bytes into its old staging path caused 1,093 dependency parses in a small fixture. Its provenance-based fallback omission of identical private captures reduced that fixture to two root parses and the real Gimbal generation completed with 391 unchanged outputs. This is a consumer fallback concern, not decorator memoization.
- Long-lived owners must not retain every edited universe indefinitely. SetMaxUniverses evicts complete least-recently-used type graphs without mutating returned objects; it bounds graph versions, not total bytes. Invalidation still uses full compatibility checks.
- A captured edit of Gimbal's real three-file review workflow took 117–118 ms through current Session.Load; using its retained exact imports and metadata took 0.17 ms for a body edit and 0.28 ms for an API field edit. Both lanes asserted local constant 23 and the changed field type. This isolated experiment implements no general metadata invalidation. Repeated native-overlay metadata still cost 112–115 ms: avoiding discovery for ordinary edits is the main remaining opportunity, beyond amortizing temporary overlay writes.

- The pinned standalone Staticcheck does not understand golangci-lint's nolint directive. Its separate lint:ignore directive is required for the compiler archive reader on Go 1.27; the complete `just lint` recipe now passes.
- Prepared View validity comes from complete private input snapshots, source/header/config identity and reverse dependency invalidation. It has no TTL. LRU evicts complete compatible universes only; source checking a changed dependency does not invent a new compiler ExportFile. Structural changes rediscover through Go.
- Tests remove Go from PATH after initial discovery and still obtain body constant 23, changed dependency constant 29 and an int field through both reverse importers; earlier returned graphs remain unchanged. Import, build-tag, module and file-membership changes instead attempt Go refresh. Derived FileSets discard historical edited files, and obsolete native-overlay backing files are removed on Update.
