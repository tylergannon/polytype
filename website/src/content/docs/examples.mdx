import { Card, CardGrid } from '@astrojs/starlight/components';

These examples focus on decisions you need to make. Every page links to compiling
repository examples when you need the complete package and generated output.

<CardGrid>
  <Card title="Optional and nullable" icon="open-book" href="/features/optionality/">
    Model an omitted property separately from a required property whose value may be null.
  </Card>
  <Card title="Enums" icon="list-format" href="/features/enums/">
    Generate string enums or expose meaningful names for integer constants.
  </Card>
  <Card title="Interfaces" icon="puzzle" href="/features/interfaces/">
    Register implementations and generate a discriminated `anyOf` schema.
  </Card>
  <Card title="Shared definitions (Ref)" icon="link" href="/features/ref-types/">
    Render a type once as a `$ref` into `$defs` instead of inlining it everywhere.
  </Card>
  <Card title="Provider schemas" icon="setting" href="/features/providers/">
    Supply field schemas at runtime when static generation is not enough.
  </Card>
  <Card title="devalue transport" icon="laptop" href="/guides/devalue/">
    Generate strict Go codecs for SvelteKit's devalue wire format from the same types.
  </Card>
</CardGrid>

The repository also contains complete, executable packages under
[`examples/`](https://github.com/tylergannon/polytype/tree/main/examples), and a
devalue codec module covering every grammar node kind under
[`devalue/codegen/testdata/fixture`](https://github.com/tylergannon/polytype/tree/main/devalue/codegen/testdata/fixture).

For a compact source-generated reference, see the installable skill's
[`references/examples.md`](https://github.com/tylergannon/polytype/blob/main/skills/polytype/references/examples.md).
